# Goal NN — Name

## 목적

이 Goal이 만드는 하나의 결과를 적는다.

## 왜 지금 필요한가

선행 문제와 다음 Goal에 제공할 경계를 적는다.

## 선행조건

- 선행 Goal commit이 main에 포함돼 있다.
- worktree가 clean하다.
- 요구 runtime과 기준선 테스트를 확인했다.

## 범위

- 이 Goal에서 허용되는 변경

## 제외 범위

- 다음 Goal로 미룰 변경

## 허용되는 기능·프로토콜 변화

- 기본값은 없음

## 구현 계약

- 상태 원천, 신뢰 경계, 실패·timeout·shutdown처럼 구현 전에 고정할 계약

## 예상 영향 파일

- 실제 조사 후 갱신

## 완료 기준

- 관찰 가능한 결과

## 자동 검증

- 명령과 기대 결과

## 수동 검증

- 브라우저 또는 운영 흐름

## 보안·데이터 검토

- 신뢰 경계와 데이터 영향

## 커밋 계획

- 한 commit에 한 변경 이유

## Rollback

- 되돌릴 commit과 데이터 호환성

## 즉시 중단 조건

- 범위 확장이나 사용자 결정이 필요한 조건

## Merge Gate

- 사용자 승인 전 수행하지 않을 작업
- 다음 Goal 선행조건
