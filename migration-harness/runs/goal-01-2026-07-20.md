  - Node 24.18 계열을 고정하고 dev, typecheck와 build 명령을 추가했다.
  - 기존 `npm start`는 Express production runtime 진입점으로 유지했다.
- `vite.config.mjs`
  - `src/client`를 root로 사용하고 index, lobby, single, multiplayer 네 HTML input과 `dist/client` output을 구성했다.
  - 개발 `/socket.io` HTTP/WebSocket proxy와 `/` index mapping을 추가했다.
- `tsconfig*.json`
  - client/server/test resolution과 type library를 분리했다.
  - 기존 JavaScript는 `allowJs: true`, `checkJs: false`로 공존하고 새 TypeScript만 strict 검사한다.
- `src/client/game/entry/theme.ts`
  - dependency가 낮은 client leaf 하나를 DOM type이 있는 TypeScript로 변환했다.
- `src/client/game/runtime/sound.js`, `src/client/pages/*.html`
  - sound asset을 Vite가 추적하는 module URL로 바꾸고 네 page의 `.ts` import를 갱신했다.
  - Express에서 `/`로 제공된 index의 상대 click 경로가 `/pages` 아래로 유지되도록 base URL을 명시했다.
- `src/server/init.js`
  - production static root를 source directory가 아닌 명시적 build output `dist/client`로 전환했다.
- `scripts/verify.sh`
  - Git whitespace, TypeScript 경계, Vite build와 기존 Node test를 한 gate로 묶었다.
- `e2e/navigation.spec.js`
  - href 문자열이 아니라 root의 실제 click으로 single Canvas와 lobby UI 진입을 검증한다.

React, React Router, root `type: module`, server 전체 TypeScript, typed Socket contract와 Goal 2 session 보안은 추가하지 않았다. gameplay 규칙, Socket.IO event 의미와 log/dataset schema 변화도 없다.
