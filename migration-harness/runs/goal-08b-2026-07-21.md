## 타입과 모듈 경계

- 기존 값 모듈이 runtime handle/display snapshot, Canvas/DOM adapter, sound/input cleanup, multiplayer lifecycle, placement dataset·heuristic·V4 decision 타입을 직접 export한다. 별도 type registry, manager나 framework는 만들지 않았다.
- Goal 8A의 `PieceType`, `Board`, `PieceState`, `GameState`, `BoardMetrics`를 재사용한다. 외부 model/JSON/Socket 값은 `unknown`에서 기존 validator 또는 Zod parsed output으로 좁힌다.
- `roomClient.ts`의 browser Socket.IO global은 dependency 없는 private structural type이다. page-facing `PlayerSession`에는 공개 `playerId`와 `nickname`만 있으며 credential token, socketId와 server-private 필드는 없다.
- rename과 page TSX, server dynamic import, test/script consumer의 `.ts` specifier 갱신을 같은 목적 commit에 포함했다. `rewriteRelativeImportExtensions`가 browser 및 `dist/server/client` output의 import를 `.js`로 변환한다.
- `erasableSyntaxOnly`, `verbatimModuleSyntax`와 `import type` 계약을 지켰다. `any`, `@ts-ignore`, `@ts-nocheck`, enum, namespace, parameter property와 broad assertion은 추가하지 않았다.
- React는 display/lifecycle만, runtime과 `gameState`는 gameplay 상태를 계속 소유한다. reconnect, BFCache, disposer, timer, sessionStorage/handshake와 V4 checksum 의미는 변경하지 않았다.
- 리뷰에서 ranker canonicalization이 malformed group validation보다 먼저 필드를 읽던 회귀를 고쳐 `null`, `[null]`, `candidates:null`이 BASE의 `INVALID_TRAINING_GROUPS`/`INVALID_DECISION_GROUP`을 반환하게 했다. `INPUT_ACTION`은 `as const` literal union이며 unsupported runtime 방어는 유지한다.
- `BrowserSocket.emit`과 `emitAuthenticated`는 기존 `ClientToServerWirePayload<K>` generic으로 연결했다. `sendGameInput`의 action, 숫자와 expected transform은 기존 wire union에서 파생하며 Zod schema와 payload 의미는 바꾸지 않았다.
- persisted credential과 active server session 타입을 분리해 저장값 판정에 `resumed`를 요구하지 않는다. 각 session-ready subscriber는 별도 `{ playerId, nickname }` projection을 받으며 token은 page-facing 타입에 없다.
- `tetrisMulti.tsx`는 `RuntimeDisplaySnapshot`, `RuntimeDisplayHandle`, `MultiplayerGameSession`, `PieceType`과 session error/disconnect 타입을 소유 모듈에서 import하며 `as GameSession`, piece key assertion과 복제 타입을 제거했다.

## 수동 검증

- Single: 실제 Canvas에서 left, rotate, soft drop, hold와 hard drop을 수행하고 score, hold/next preview와 restart를 확인했다. sound preference와 BFCache 계약은 자동 회귀와 함께 확인했다.
- PVP: 별도 Host/Guest tab에서 room join/start, 양쪽 HUD와 overlay, guest 입력·hold·hard drop을 확인했다. guest reload 뒤 같은 room과 score가 복구되고 listener/timer 중복 징후가 없었다.
- PVE: 수동으로 experimental V4 상대를 시작해 visible descent, AI score `252`, line `1` 진행과 human input 경로를 확인했다.
- 최종 production E2E에서 normal/hard heuristic 선택과 휴리스틱 badge, 명시적 `placement_v4` 선택과 runtime badge, PVE server game-over의 실제 `match:finish` 수신·승패 표시·같은 방 재시작을 확인했다.
- 같은 production E2E가 Host/Guest 각 token이 해당 URL, DOM HTML과 수집된 console message에 없고 browser console error/pageerror가 0개임을 확인했다.

## Bundle, 남은 위험과 rollback

- shared tetris chunk는 직전 문서 기준 34.93 kB(gzip 10.93 kB)에서 36.31 kB(gzip 11.29 kB), roomClient chunk는 76.86 kB(gzip 21.19 kB)에서 77.39 kB(gzip 21.31 kB)로 증가했다. 새 dependency와 별도 runtime chunk는 없다.
- Chromium local dev/production과 수동 기능을 검증했지만 WebKit/Firefox, 장시간 soak와 외부 network 조건은 실행하지 않았다.
- server source는 Goal 8C까지 JavaScript/CommonJS 경계가 남고 test/e2e/script 자체의 선택적 TypeScript 정리는 Goal 8D 범위다.
- rollback은 `docs: finalize Goal 8B review gate` → `842d23b` → `386c853` → `9a45ab7` → `0ee3736` → `189faf5` → `cda715e` → `7ca30b3` 순서로 역순 revert한다. rename과 consumer specifier를 함께 되돌리고 generated artifact만 부분적으로 복구하지 않는다.
- Goal 8B만 완료 처리하고 local merge gate에서 멈춘다. push, main merge, branch 삭제, Goal 8C/8D와 SPA 작업은 수행하지 않는다.
