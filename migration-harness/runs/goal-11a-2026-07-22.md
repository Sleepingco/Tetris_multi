## 정책과 구현 경계

- `src/server/httpSecurity.ts`는 Node 표준 `URL`과 `ServerResponse` 경계만 사용한다. CSP는 `default-src 'none'`에서 시작해 실제 필요한 same-origin script/style/media, data SVG image와 connect destination만 연다.
- 네 page가 공유하는 theme pre-paint script의 SHA-256 hash 하나와 세 종류의 inline theme style SHA-256 hash를 고정했다. artifact test가 clean build HTML의 inline script/style 수와 hash를 다시 계산하고 예상하지 못한 inline handler와 static style attribute를 거부한다.
- HTML의 유일한 정적 `#multiplayerRoot` style attribute만 `tetris.css`로 옮겼다. 최초 report-only에서 React style prop과 개별 `element.style.display`는 `style-src-attr` 위반을 만들지 않아 승인 조건대로 변경하지 않았다.
- `server.prependListener("request", ...)`는 Socket.IO Server 생성 뒤 등록되고 response header만 설정한다. write/end는 호출하지 않으며 Express·정적 asset·Socket.IO client와 polling 응답에 같은 header를 적용한다. Express finalhandler가 404 CSP를 덮어쓰지 않도록 마지막 404 handler가 같은 header 상태에서 plain 404를 끝낸다.
- 기본 mode는 enforce다. `CSP_MODE=report-only`일 때만 report-only header를 사용하며 두 CSP header가 동시에 존재하지 않는다. malformed mode와 malformed `CSP_CONNECT_ORIGINS`는 시작 시 예외로 fail closed한다.
- `CSP_CONNECT_ORIGINS`는 `SOCKET_ALLOWED_ORIGINS`와 독립적이다. WHATWG URL로 `http`, `https`, `ws`, `wss` protocol, credential 부재, origin-only path, query/fragment 부재와 wildcard 부재를 검증하고 정규화된 exact origin만 `connect-src`에 추가한다. current `roomClient`의 same-origin `io()` 계약은 바꾸지 않았다.
- `/socket.io/socket.io.js`, Vite `/socket.io` proxy와 Socket.IO built-in client serving을 유지한다. first-party `.ts`, `.tsx`와 bundle map은 404다. `/socket.io/socket.io.js.map`은 공개 third-party dependency source만 포함하는 기존 200 예외로 유지하고 integration/release test에서 의도적으로 고정했다.
- Socket shared Zod runtime은 공식 `z.config({ jitless: true })`를 사용한다. schema, parsed output과 wire protocol은 변경하지 않고 CSP가 금지한 eval probe만 실행하지 않는다.
- 공통 HTTP header는 `X-Content-Type-Options: nosniff`, `X-Frame-Options: DENY`, `Referrer-Policy: no-referrer`이며 Express `x-powered-by`는 비활성화했다.

## 남은 위험과 rollback

- 자동 browser 검증은 Chromium local production/Vite-dev에 한정한다. WebKit/Firefox, 외부 TLS termination, reverse proxy와 실제 production hostname은 미검증이다.
- production의 same-origin polling은 `'self'`로 허용된다. browser별 WebSocket scheme 해석이나 별도 Socket destination이 필요하면 `SOCKET_ALLOWED_ORIGINS`를 재사용하지 말고 exact `CSP_CONNECT_ORIGINS`를 배포 설정에 추가한다.
- 고정 inline hash는 HTML bootstrap 내용이 바뀌면 artifact gate에서 실패한다. 실패 시 새 inline 코드를 넓게 허용하지 말고 내용과 hash를 함께 리뷰한다.
- Socket.IO third-party client map은 built-in serving 보존을 위한 승인된 예외다. 이를 비공개로 바꾸려면 client distribution 경로 변경을 별도 Goal로 설계한다.
- rollback은 `docs: record Goal 11A security hardening` (현재 commit) → `9a33e90` → `98e89ab` 순서로 역순 revert한다. 운영 완화가 필요하면 전체 CSP를 제거하거나 `unsafe-inline`을 추가하지 않고 먼저 `CSP_MODE=report-only`로 전환한 뒤 문제가 된 directive만 좁게 수정한다.
- Goal 11A만 완료 처리하고 clean local merge gate에서 멈춘다. push, main merge, branch 삭제, Goal 11B와 Goal 8D/9/10/SPA는 수행하지 않는다.
