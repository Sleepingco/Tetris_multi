## 변경 계약

- PVE 7-bag T-Spin E2E와 해당 시나리오 전용 이동·hold·drop·corner setup helper 및 상수를 제거했다.
- T-Spin core 판정은 `test/testTSpin.js`, authoritative T-Spin placement scalar는 `test/testPlayerGameplayStep.js`, runtime placement result와 attack log는 `test/testTetrisRuntime.js`의 결정론적 테스트가 계속 보장한다.
- pending garbage는 기준 snapshot 이후 sequence와 piece index 증가, board fingerprint 변화와 garbage cell 증가로 실제 적용을 확인한다.
- 같은 authoritative sequence가 유지되는 동안 UI 숫자와 `is-danger` class가 최신 snapshot의 pending 값과 일치하는지 확인한다. lock 뒤 새 AI attack으로 pending이 다시 증가하는 정상 동작을 허용한다.
- fixed sleep, timeout 증가, retry, skip, worker 변경과 production debug/test API를 추가하지 않았다.
