## 타입과 모듈 경계

- `blocks.ts`만 `PieceType = keyof typeof BLOCKS`를 export한다. `piece.ts`는 `import type`으로 이를 소비하고 `PieceState`의 빈 sentinel을 `PieceType | ""`로 보존한다.
- board, piece, move/step, attack/garbage/T-Spin과 mutable/serialized state 타입은 각 기존 값 모듈이 소유한다. 공용 type registry, enum, namespace와 parameter property는 추가하지 않았다.
- client/test에는 `erasableSyntaxOnly`와 `verbatimModuleSyntax`를 적용했고 type-only dependency는 `import type`을 사용한다. Node가 직접 읽는 source는 type stripping만으로 실행 가능하다.
- `rewriteRelativeImportExtensions`는 기존 base tsconfig에서 client와 server build가 함께 상속한다. source `.ts` specifier는 Vite bundle과 `dist/server/client`의 `.js` import로 변환된다.
- root CommonJS, `src/client/package.json` ESM marker, `allowJs`와 production의 compiled `dist/server/app.js` 실행 경계는 그대로다. 새 loader나 dependency는 없다.

## Serialization과 artifact 동등성

- `deserializeGameState()`는 기존 fallback 의미를 유지하도록 `Partial<SerializedGameState>`를 받는다. serialization schema와 runtime 의미는 바꾸지 않았다.
- 회귀 테스트는 현재 구현이 복제하는 board와 각 row, active/pending piece, pieceQueue/bag/inputQueue 배열 컨테이너만 reference 비공유로 고정한다. inputQueue 원소 객체는 기존처럼 deep clone하지 않는다는 점도 명시적으로 확인한다.
- clean build artifact test는 실제 compiled `gameCoreLoader`로 `BLOCKS.tree`, 빈 20×10 board와 대표 `move_left` intent/move fixture를 실행한다. 모델·contract·ticker/socket별 중복 parity framework는 만들지 않았다.

## Bundle, 남은 위험과 rollback

- shared tetris bundle은 기준 34.82 kB(gzip 10.90 kB)에서 34.93 kB(gzip 10.93 kB)로 증가했다. 새 dependency나 별도 runtime chunk는 없다.
- 아직 JavaScript인 consumer는 `allowJs:true`, `checkJs:false` 경계에 남아 있어 해당 파일 자체의 strict TypeScript 검사는 Goal 8B 이후 범위다.
- Chromium local production과 수동 시나리오를 검증했지만 WebKit/Firefox, 장시간 soak와 외부 network 조건은 실행하지 않았다.
- rollback은 이 branch의 문서 commit, `47c10e6`, `61de0a1`을 역순으로 revert한다. rename과 consumer specifier를 함께 되돌리고 output만 부분적으로 되돌리지 않는다.
- Goal 8A만 완료 처리하고 local merge gate에서 멈춘다. push, main merge, branch 삭제, Goal 8B와 SPA 작업은 수행하지 않는다.
