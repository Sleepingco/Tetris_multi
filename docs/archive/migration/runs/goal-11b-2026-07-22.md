## Advisory와 실행 경로

- fresh `npm audit`는 `body-parser@2.2.2`의 GHSA-v422-hmwv-36x6/CVE-2026-12590 low advisory 한 건을 보고했다. invalid 또는 `NaN` limit가 request body size enforcement를 건너뛰게 하는 availability 위험이며 patched version은 `2.3.0`이다.
- dependency 경로는 root `express@5.2.1` → `body-parser@^2.2.1` → installed `2.2.2`다. Express는 `body-parser` 모듈을 로드한다.
- 현재 애플리케이션은 `express.json()`, `express.urlencoded()`, `express.raw()`, `express.text()` 또는 `body-parser` middleware를 생성하지 않는다. 따라서 advisory의 invalid-limit 처리 경로는 현재 request flow에서 도달하지 않는다.
- 현재 reachability가 낮더라도 Express의 기존 semver 범위와 Node `>=18`에 맞는 patched `2.3.0`이 존재하므로 known advisory를 남기지 않는 최소 lockfile 갱신을 선택했다. `body-parser`를 direct dependency로 추가하거나 Express를 갱신하지 않았다.

## Conda 재현성과 남은 위험

- 기존 사용자 `tetris-ml` environment는 변경하거나 삭제하지 않았다.
- `/private/tmp/tetris-goal11b-conda-prefix`에 `environment-ml.yml`을 설치해 Python `3.12.13`, NumPy `2.5.1`, SciPy `1.18.0`, scikit-learn `1.9.0`, pandas `3.0.3`, ipykernel `7.2.0`, nbconvert `7.17.1` exact pin을 확인하고 Python 115/115를 통과한 뒤 해당 임시 prefix만 제거했다.
- `environment-ml.yml`은 top-level version을 exact pin하지만 transitive package의 version/build/channel artifact 전체를 고정하는 lockfile은 아니다. 이후 defaults repodata와 solver가 달라질 수 있는 재현성 한계는 남는다. 이번 Goal에는 conda-lock, pip-audit, helper나 dependency를 추가하지 않았다.
- npm audit는 npm advisory database에 공개된 항목만 다루며 미래 advisory와 운영 환경 자체를 보증하지 않는다. WebKit/Firefox, 외부 TLS/reverse proxy와 장시간 dependency soak는 이번 local Chromium gate 범위 밖이다.

## Rollback과 merge gate

- rollback은 `docs: record Goal 11B dependency hardening` (현재 commit) → `3fe121e` 순서로 역순 revert한다.
- dependency commit revert 뒤 `npm ci --ignore-scripts`를 실행하면 기준 lock resolve로 돌아간다.
- Python/Conda 파일은 변경하지 않아 별도 rollback이 없다.
