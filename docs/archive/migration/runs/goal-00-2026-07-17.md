사용자가 Goal 0의 제한적 범위 예외로 `src/server/init.js`의 root `sendFile()` 한 줄 수정을 승인했다.

- 이 예외는 baseline E2E 변경과 별도 commit `45f4c2a`로 기록했다.

## 리뷰 지적 정정

초기 single E2E는 네 키를 연속 호출한 뒤 최종 score와 하단 board만 확인해 이동, 회전과 soft drop 결과를 독립적으로 증명하지 못했다. Goal 0 리뷰에 따라 다음과 같이 정정했다.

- `Math.random()`을 테스트 페이지에서만 고정해 첫 조각을 비정사각형 T 조각인 `tree`로 만든다.
- Playwright clock을 일시 정지하고 입력마다 16ms input tick만 진행해 자동 중력과 soft drop을 구분한다.
- 이동은 동일한 불투명 T cell 집합이 왼쪽으로 한 열 이동했는지 확인한다.
- 회전은 수평 T cell 배치가 90도 배치로 변했는지 정확한 Canvas 좌표로 확인한다.
- soft drop은 회전된 cell이 한 행 내려가고 화면 밖 cell이 새로 보이는지 확인한다.
- hard drop은 ghost가 아닌 불투명 T cell 네 개가 하단에 고정되고 화면 score가 증가했는지 확인한다.
- production debug global, gameplay 로직과 runtime 공개 API는 추가하지 않았다.

## 실패와 미실행 범위

- dependency 복원 전 첫 E2E는 local Playwright binary 부재로 실행되지 않았다. `npm ci` 후 재시도했다.
- 수정 전 E2E는 root 404로 readiness timeout이 발생했고, 승인된 호환성 예외 적용 후 재현되지 않았다.
- main 동기화 후 HTTP smoke의 기본 포트 5500은 기존 프로세스가 사용 중이어서 서버 기동이 `EADDRINUSE`로 실패했다. 기존 프로세스를 종료하지 않고 임시 포트 5517에서 동일 경로를 검증했다.
- packet loss, 높은 외부 latency, 장시간 soak, WebKit과 Firefox는 검증하지 않았다.
- Node 24 전환은 Goal 1 범위이므로 수행하지 않았다.

## 보안·데이터 영향

- `dotfiles: "allow"`를 사용하지 않아 dotfile 노출 범위를 넓히지 않았다.
- session, reconnect, authorization과 Socket.IO payload 계약은 변경하지 않았다.
- test fixture에 token, secret, 개인 데이터를 추가하지 않았다.
- JSONL, Python parity, dataset, model artifact와 production log를 변경하지 않았다.
