# Documentation Mode

이 모드는 코드 설명, 문서 정리, 개념 분해에 사용한다.

## 목표

- 현재 코드가 왜 이렇게 생겼는지 설명한다.
- 데이터 흐름과 책임 경계를 드러낸다.
- 학습자가 다음에 혼자 읽을 수 있게 맥락을 정리한다.

## 입력

- 대상 파일 또는 함수
- 궁금한 지점
- 필요하면 관련 호출 흐름

## 출력 형식

1. 왜
   - 이 코드가 필요한 이유
2. 무엇
   - 입력, 출력, 상태 변화
3. 어떻게
   - 실행 순서와 핵심 분기
4. 확인 포인트
   - 직접 읽어볼 줄기 또는 로그 포인트

## 이 프로젝트에서 특히 볼 것

- `core`와 `render` 책임이 섞여 있는지
- `runtime`이 실행 흐름만 조율하고 있는지
- 상태의 단일 진실 원천이 유지되는지
- 멀티플레이 또는 AI 확장 시 재사용 가능한 순수 로직 경계가 있는지

## 피해야 할 것

- 파일 전체를 단순 요약만 하기
- "그냥 이렇게 동작한다" 식으로 이유 없이 끝내기
- 실제 호출 흐름을 확인하지 않고 추측으로 설명하기
