# Review Mode

이 모드는 코드 변경 후 위험 요소와 회귀 가능성을 검토할 때 사용한다.

## 목표

- 버그, 설계 위반, 회귀 위험을 먼저 찾는다.
- 칭찬이나 요약보다 문제를 우선한다.
- 플레이 가능성, 책임 분리, 검증 누락을 본다.

## 출력 형식

1. 발견된 이슈
2. 영향 범위
3. 왜 문제인지
4. 필요한 테스트 또는 수동 검증

## 우선순위

- 게임이 깨지는가
- 상태 원천이 흔들리는가
- `core / runtime / render / net` 경계가 섞였는가
- 멀티플레이 확장 시 desync 위험이 커지는가
- 수정 의도와 다른 부작용이 생기는가

## 이 프로젝트에서 자주 보는 항목

- 조각 고정, 줄 삭제, 홀드, 회전 회귀
- 점수/UI만 맞고 실제 상태는 어긋나는 문제
- 렌더 계층이 판정 로직을 떠안는 문제
- 네트워크 계층이 게임 규칙을 직접 결정하는 문제
- AI 변경이면 `ai-analysis.md`의 결정론, 불변성, baseline, 데이터 품질 기준 누락

## 결과가 없을 때

- 이슈 없음이라고 명시한다.
- 그래도 남는 검증 공백은 따로 적는다.
