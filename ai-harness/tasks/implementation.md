# Implementation Mode

이 모드는 작은 기능 구현이나 필요한 코드 추가에 사용한다.

## 목표

- 현재 구조를 존중한 채 필요한 최소 코드만 추가한다.
- 기능 추가와 구조 변경을 가능하면 분리한다.
- 수정 후에도 즉시 플레이 가능한 상태를 유지한다.

## 출력 형식

1. 변경 이유
2. 영향 파일
3. 최소 구현안
4. 검증 방법

## 구현 원칙

- 기존 책임 경계를 먼저 확인한다.
- `render`에서 게임 규칙을 결정하지 않는다.
- 새 추상화는 실제 중복이나 명확한 경계가 있을 때만 만든다.
- 큰 파일 전체 교체 대신 필요한 부분만 수정한다.

## 이 프로젝트에서 우선하는 방향

- 입력은 입력 계층에서 정규화한다.
- 판정은 `core` 또는 실행 흐름에서 처리한다.
- 표시용 계산은 `render`에 둔다.
- 멀티플레이를 고려하더라도 지금 당장 필요 없는 일반화는 넣지 않는다.

## 검증 예시

- 조작 입력 후 기존 플레이 흐름이 유지되는가
- 점수, 홀드, 다음 큐, 게임오버가 깨지지 않는가
- 새 기능과 무관한 기존 동작이 회귀하지 않는가
